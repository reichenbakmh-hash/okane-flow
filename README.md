# Okane Flow PWA

## Fichiers à envoyer sur GitHub

- `index.html`
- `manifest.webmanifest`
- `service-worker.js`
- le dossier `icons`

Ne modifiez pas les noms ou les chemins, sinon le navigateur fera sa petite crise administrative.

## Publication avec GitHub Pages

1. Envoyer tous les fichiers à la racine du dépôt.
2. Ouvrir `Settings > Pages`.
3. Sélectionner `Deploy from a branch`.
4. Choisir `main` et `/ (root)`.
5. Ouvrir l'adresse GitHub Pages une fois le déploiement terminé.
6. Sur Android avec Chrome : ouvrir le menu puis `Installer l'application`, ou utiliser le bouton d'installation dans Okane Flow.

## Fonctionnement

- Installation sur l'écran d'accueil
- Fenêtre autonome sans barre d'adresse
- Données sauvegardées automatiquement dans le navigateur
- Fonctionnement hors ligne après le premier chargement réussi
- Mise à jour automatique lors du prochain chargement en ligne

## Important

Les données restent locales à l'appareil et au navigateur. Désinstaller l'application ou effacer les données du navigateur peut supprimer les données locales. Utilisez aussi la fonction de sauvegarde de l'application pour conserver une copie.
