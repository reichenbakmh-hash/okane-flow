Sauvegarde & restauration

Options simples pour conserver vos données sans serveur.
  1. Exportez vos données (bouton "Exporter") pour obtenir un fichier JSON.
  2. Importez ce fichier sur n'importe quel appareil (bouton "Importer").
  3. Copiez le fichier dans votre stockage cloud (Google Drive, Dropbox) pour sécurité.
Astuce : utilisez un mot de passe fort pour chiffrer le fichier exporté si vous le stockez sur un cloud public.

Profil local

Création d'un profil local protégé par mot de passe (stockage local seulement).
